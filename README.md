# Bowls Competition Manager

An offline phone app for lawn bowls club competitions: tabs-in teams, the draw, rink moves for game 2, skip cards, scores and results.

**Open / install:** https://wobstix.github.io/bowls

- Works offline after the first open. Add it to the home screen from the browser menu.
- All club data stays on the device. Use *Backup / restore* to keep a copy or pass it to another phone.

Engine tests: `node tests/engine.test.js`
